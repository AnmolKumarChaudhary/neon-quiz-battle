# Neon Quiz Battle

A cyberpunk-styled, nickname-only multiplayer trivia game starter using React, TypeScript, Vite, Supabase Postgres/Realtime, and a server-side Supabase Edge Function.

## Features
- Room creation and room-code joining
- Gaming & Pop Culture, General Knowledge, and Science & Technology
- Shared server timestamp for 15-second rounds
- Private answer submissions and server-side scoring
- Speed bonus, live leaderboard, winner screen, and restart
- Responsive mobile and desktop UI

## Setup
Follow [`SETUP.md`](./SETUP.md) for Supabase configuration, local development, and Vercel deployment.

## Status
Source files are generated, but the application is not deployed or verified against a live Supabase project. Live multiplayer and deployment require the project owner to configure Supabase and Vercel.
